# Planned Features

## Phase 2 — Dynamic Data
- **League selector** — Dropdown to switch trade URLs between active leagues instead of hardcoded.
- **Dynamic stat ID lookup** — Fetch `https://www.pathofexile.com/api/trade/data/stats` at runtime instead of static table.
- **Parse presets from `ressources/idealMercs.md`** — Load CptLance presets dynamically instead of hardcoded HTML.

## Phase 3 — Quality of Life
- **Copy trade link to clipboard** — One-click copy button alongside "Open in PoE Trade".
- **Multiple warrant parsing** — Handle pasting multiple warrants at once.
- **Local storage favorites** — Save favorite mercs for quick re-search.
- **Error highlighting** — Show which lines failed to parse and why.
